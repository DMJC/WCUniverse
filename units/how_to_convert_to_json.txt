A brief guide on how to convert to JSON
=======================================
units.csv is the source; units.json is generated from it. After editing units.csv run:

    python3 convert_units.py

It reads the column names from units.csv's own header row, adds the upgrade
fields the engine needs (Upgrade_Type, shield, shield_facets, armor, repair) and
bakes each ship's "Upgrades" column into its stats. See the script for details.

Do not use parser.py: it assumes upstream Vega Strike's column list, which does
not match WCU's units.csv, and shifts most values onto the wrong keys.
